# dfu-mods

Quality-of-life and visual mods for [Daggerfall Unity](https://www.dfworkshop.net/) (built and tested against DFU 1.1.1).

| Mod | What it does |
| --- | --- |
| [junk-loot-filter](junk-loot-filter/) | Quick loot with a filter, quick sell, junk tagging, item locks, a smarter item hover with equipped-item comparison, smaller centred windows, rebindable keys. |

Each mod lives in its own folder with its own README and build notes. No game files or third-party assets are
included here.
